Agent tokens allow AI coding agents to access your feedback programmatically through the MCP server or REST API.

## Creating a token

1. Go to [Integrations](https://faster-fixes.com/integrations)
2. Click **Create Token**
3. Name your token (e.g. "Claude Code - Main Project")
4. Copy the token immediately — it won't be shown again

The token is prefixed with `ff_agent_` for easy identification.

## Scopes

Each token has fine-grained permissions:

| Scope | Dashboard label | Permission |
|-------|-----------------|-----------|
| `feedbacks:read` | Read feedbacks | List feedback items, board columns, and team comments |
| `feedbacks:update_status` | Update feedback status and column | Update feedback status (new, in_progress, resolved, closed) and move feedback between board columns |
| `feedbacks:comment` | Add comments | Add team comments, including a closeout comment with a status change or column move |
| `feedbacks:create` | Create feedbacks | Import feedback items |

New tokens default to `feedbacks:read`, `feedbacks:update_status`, and `feedbacks:comment`.

Scopes are fixed when a token is created. Existing tokens are not granted `feedbacks:comment` automatically: to let an agent comment, create a new token with **Add comments** checked. A status change or column move that includes a comment without this scope returns `403` and changes nothing.

Agent comments appear in the dashboard under the token's name with an **Agent** badge. They cannot be edited; owners and admins can delete them.

## Rate limits

| Action | Limit |
|--------|-------|
| Read operations | 200 requests/hour |
| Write operations | 50 requests/hour |

Rate limits are tracked per token. Exceeding the limit returns a `429 Too Many Requests` response.

## Security

- Tokens are hashed with SHA-256 — the raw token is never stored
- Token validation uses constant-time comparison to prevent timing attacks
- `lastUsedAt` is tracked for audit purposes
- Tokens can be revoked instantly by disabling them

## Managing tokens

- **Revoke**: Disable a token immediately. The MCP server or API calls using it will fail.
- **Delete**: Permanently remove the token.
- Create separate tokens per agent or environment for granular access control.
